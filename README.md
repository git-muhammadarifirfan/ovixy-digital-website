# Ovixy Digital — Website

Website resmi **Ovixy Digital**, studio pembuatan website, katalog online, dan aplikasi bisnis yang dirancang khusus untuk membantu UMKM dan pelaku jasa lokal naik kelas secara digital.

## Tech Stack

- **React** + **TypeScript** (Vite)
- **Tailwind CSS** — Utility-first styling
- **GSAP** + **Lottie** — Premium animations
- **Lenis** — Smooth scrolling
